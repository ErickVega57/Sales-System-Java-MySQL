Final Project Instructions
Welcome to your final project! This project is an opportunity for you to demonstrate your understanding of the concepts we've covered in class. Below are detailed instructions to guide you through each step of the assignment. Make sure to read through everything carefully and follow the instructions closely.

Project Overview
In this project, you will be working with a Java and OOP concepts. Your tasks will involve cloning a repository, understanding the code, creating UML diagrams, making modifications, and presenting your work.

Step-by-Step Instructions
1. Clone the Repository
Action: Start by cloning the repository from GitHub.
How to Do It:
Open your terminal or command prompt.
Use the command: git clone https://github.com/angel-chi/Sales-System-Java-MySQL
This will create a local copy of the repository on your machine.
2. Familiarize Yourself with the Code
Action: Take time to understand the existing code.
How to Do It:
Open the project in your preferred code editor.
Read through the code files related to the Seller, Product, Customer, ShippingCart, Sales, and SalesDetails entities.
Identify the relationships and functionalities of each entity.
UML Diagram:
Use a digital tool (like Lucidchart, Draw.io, or any UML software) to create a UML diagram that represents these entities.
Ensure that the diagram is clear and accurately reflects the structure of the code.
Important: Add the UML diagram to the README file in the repository.
3. Build and Run the Project
Action: Compile and execute the project.
How to Do It:
Follow the instructions in the repository to build the project without using an IDE.
Pay attention to any errors that occur during the build process.
Documentation:
Identify at least three errors that you encounter.
For each error, document:
What the error was.
How you resolved it.
Include this information in the README file.
4. Modify the User Interface (UI)
Action: Change the language of the UI to Spanish.
How to Do It:
Go through the UI code and replace all English text with Spanish.
Ensure that the translations are accurate and contextually appropriate.
User-Friendly Changes:
Modify UI elements to make them understandable for users without programming knowledge.
For example, change the label "DNI" to "Usuario" or something more intuitive.
5. Propose Improvements
Action: Suggest enhancements for the Seller, Sales, Customer, and Product entities.
How to Do It:
Analyze each entity and think critically about how they can be improved.
Consider Object-Oriented Programming principles such as encapsulation, inheritance, and polymorphism.
Your proposals can include:
Adding new attributes or methods.
Creating new classes or interfaces.
Documentation:
Clearly outline your proposed changes in the README file.
6. Implement Changes in the UI
Action: Apply at least two of your proposed changes to the UI.
How to Do It:
Choose two of your proposed improvements and implement them in the UI code.
Ensure that these changes enhance the user experience and functionality.
Deliverables
1. Create a Pull Request
Action: Submit your work on GitHub.
How to Do It:
Push your changes to a single personal branch. Both students should push changes to THE SAME BRANCH.
Create a pull request and paste the link in this Teams Assignment.
2. Create a Video Presentation
Action: Record a video showcasing your project.
How to Do It:
Use screen recording software to capture your screen.
In the video, make sure to include the following:
Introduce yourself with your full name (both students).
Show the build and run process without using any IDE.
Log in and display all available UIs in a general way.
Walk through the work you completed from point 2 to point 6.
Upload: Choose a platform to upload your video (like YouTube or Vimeo) and paste the link in the README file under a special section for it.
3. Official Presentation
Action: Prepare to present your project in class.
How to Do It:
Be ready to explain your work and the changes you made.
Prepare to answer any questions that your teacher may ask about your project.
Final Notes
Make sure to review your work before submission to ensure everything is complete and accurate.
Don’t hesitate to ask for help if you encounter any challenges during the project.
Good luck, and have fun with your final project!
